# React Native Skill

## Purpose

Generate deterministic, minimal React Native components compatible with Expo SDK 55 and React Native 0.83.x.

## Rules

- Always use functional components.
- Always use React Hooks.
- Always use TypeScript.
- Always use StyleSheet.create.
- Always use Pressable instead of TouchableOpacity.
- Always use FlatList for lists.
- Always generate tablet‑friendly UI.
- Never use deprecated APIs.

## Components

- Always include SafeAreaView for screens.
- Always include StatusBar.
- Always export default for screens.

## Navigation

- Always use Expo Router hooks: useRouter, useLocalSearchParams, useSegments.

## Animations

- Use Reanimated 3 only.

## Maps

- Use expo-maplibre-gl.
